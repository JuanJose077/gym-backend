# Gym - Backend

Proyecto backend para la app de seguimiento de rutinas y progresos de gym.

## Objetivo
Construir una API en Spring Boot con arquitectura hexagonal para registrar usuarios, rutinas y progreso.

## Git & GitFlow
- Repo inicializado con ramas `main`, `develop` y una rama de feature de ejemplo.
- README y .gitignore incluidos.

## Resumen
1. Crear rama `feature/mi-feature` desde `develop`.
2. Hacer commits atómicos y descriptivos.
3. Abrir Pull Request hacia `develop`.
